# Kindness Quest source

From this directory, use Node.js 22 and pnpm.

- Run `pnpm install --frozen-lockfile` to install dependencies.
- Run `pnpm dev` to play and edit locally.
- Run `pnpm build && node build-pages.mjs` to update the repository's root `index.html` for GitHub Pages.

Edit the scenarios and badge definitions in `src/story.ts`.
